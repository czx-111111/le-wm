This directory contains a vendored copy of the R3M encoder implementation used as a visual
backbone within DINO-WM models.

- R3M project page: `https://github.com/facebookresearch/r3m`
- Please refer to the upstream repository for full documentation and license details.

The code is included here to keep experiments self-contained. Avoid making large structural
changes locally so that it remains feasible to incorporate upstream updates or fixes if needed.
