This directory contains a vendored copy of the LPIPS (Learned Perceptual Image Patch Similarity)
implementation used for image-based evaluation metrics.

- Source project: `https://github.com/richzhang/PerceptualSimilarity`
- License and original documentation are provided upstream.

This code is included here for convenience and reproducibility. When making changes, please be
cautious and keep local modifications minimal, since upstream improvements or bug fixes may need
to be ported manually.
